# Industrial ML and Process Engineering Portfolio

This repository showcases a collection of **real industrial projects** where I applied
data science, machine learning, and process engineering to solve problems in
chemical and mining operations.

The projects in this portfolio include:

- **Anomaly detection in industrial data**
- **Soft sensor development using machine learning**
- **Predictive maintenance for critical equipment**
- **Volumetric balance for leaching area in mining**
- **Conductivity sensor analysis and filtering**
- **Analysis of iodine concentration sensor**
- **ORP (Oxidation-Reduction Potential) modeling for process control**
- **Control loop performance analysis and improvement**

Each folder in this repository corresponds to one project and contains:

- Jupyter notebooks with the analysis and models  
- A project-specific `README.md` with context, methods, and results  
- (When possible) example plots or results

---

## Highlights

- Worked with **real plant data** (sensors, process variables, lab data).
- Built **regression models, anomaly detection models and soft sensors**.
- Integrated **chemical engineering knowledge** with **machine learning**:
  control loops, ORP, leaching, contamination detection, and sensor reliability.
- Focus on **practical impact**: improving monitoring, early detection of
  problems, and decision-making in industrial environments.
